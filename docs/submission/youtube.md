Kavu: Turning Weather into Maize-Drying Jobs | Hack The Weather 2026

## Description

A harvest takes months. At the drying yard, the next few hours matter.

Try Kavu:
https://kavu-drying.web.app/

Kavu helps a maize cooperative turn JKUAT Conduit weather evidence into a practical work plan: which lot to spread, turn, cover or remeasure. The supervisor can record completed jobs, preserve a lot's history and compare measured moisture changes against a transparent drying tariff.

This walkthrough shows account creation and persistent private records, followed by a complete historical example using real Conduit observations and clearly labelled sample maize lots. Watch the plan change between missing evidence, humid weather and a useful drying window. Then follow one lot from operator jobs to a moisture reading and a KSh 2,176 drying-tariff equivalent.

The cost figure is a reference comparison using NCPB's published rate. It is not a claim of measured savings. Storage review uses a recorded moisture reading; local grain-quality procedures and aflatoxin checks remain separate.
